# 中文使用说明（本 fork 的用途）

本仓库是个人 fork，用于两件事：

1. **中文场景适配记录**：把界面文案、示例数据替换为中文业务语境（后台/看板/问答），
   改动只落在本 fork，不改上游默认行为。
2. **作品集截图**：为 https://boryac.me 的档案条目提供真实产品级界面截图，
   截图前会抹掉上游 logo、水印与默认主题色，产品名统一为 BORV 系列。

## 变更约定

- 不改上游的业务逻辑与依赖版本；
- 所有本地化改动集中在 `extra/` 与本文档，便于 rebase 上游；
- 上游许可证与版权声明原样保留。

上游项目版权归原作者，本 fork 的改动以同样的开源许可发布。
